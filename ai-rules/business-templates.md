# Business Website Templates

This file defines standard website templates for common local businesses.

Claude should use these templates when generating demo websites or production websites for small businesses.

The objective is to speed up development while ensuring that the websites contain the most relevant sections for each business type.

---

# General Rules

All templates must follow these principles:

- Simple navigation
- Mobile-first design
- Clear contact information
- Easy admin updates
- Spanish user interface

Common sections that most sites should include:

- Inicio
- Servicios / Productos
- Sobre Nosotros
- Ubicación
- Contacto
- Horarios

# Template Usage Rules

When Claude generates a new website, it should:

1. Identify the business type
2. Select the closest template
3. Adapt sections if necessary
4. Generate realistic demo content
5. Ensure the website remains simple and easy to manage

---

# Demo Content Strategy

Demo websites should include placeholder content that looks realistic.

Example:

Veterinaria San Martín  
"Más de 20 años cuidando a tus mascotas"

Restaurante La Plaza  
"Cocina casera con ingredientes frescos"

Ferretería Central  
"Todo para tu hogar y tus proyectos"

---

# Customization After Sale

Once a client purchases the website service:

- demo content should be replaced with real business data
- products should be connected to the real inventory system
- contact information should be updated
- branding should be customized
